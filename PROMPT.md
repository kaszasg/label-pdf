- Feladat egy PDF dokumentum készítő .Net 10 CLI alkalmazás készítése.
- A program egy A4-es PDF dokumentumot készít ami 5x2 címkét tartalmaz (10.5 x 6 cm).
- A program beolvas egy szöveges fájlt aminek minden sora egy címke felírata és ebből készít címkét felirattal (10db).
- Minden címkéknek legyen a szélektől 5mm-re kerete, ez alapján lesz szétvágva (vékony vonal elég).
- A címkékben tiszta nagybetűvel kell megjelenni a feliratoknak (1 felirat / címke).
- A címkékben a feliratok a lehető legnagyobb betűtípussal iródjanak ami még elfér,
  de minden felirat azonos betűméretet használjon. A felirat 2 sorba is megjelenhet, ha az jobb kitöltést ad.
- A program tegye lehetővé a betűméret megadását paraméterben opcionálisan.
- A program tegye lehetővé a bemenő és kimenő fájl megadását paraméterben, az alapértelmezett értékek input.txt és output.pdf.
- A program legyen lefordítható single file executable-ra méretre optimalizálva.
- Teszteléshez használd a labels1.txt fájlt.
- A fejlesztést követően készüljön egy SUMMARY.md fájl ami minden releváns információt tartalmaz ahhoz,
  hogy folytatni lehessen a fejlesztést.
- A fejlesztést követően legyen részletes tesztelés és ellenőrzés.
- A fejlesztést követően készüljön egy kézikönyv a MANUAL.md fájlba,
  ami a felhasználók számára minden fontos információt tartalmaz.
- Az MD fájlok, a forráskódokban lévő kommentek, log-ok, elnevezések angol nyelvűek legyenek.
